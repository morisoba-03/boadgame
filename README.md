# みんなのボドゲ

スマホ1台をみんなで回して遊べる、言葉あそび中心のボードゲーム集です。
ビルド不要の静的サイトなので、ファイルを開くだけで動きます。

## 遊べるゲーム（9種類）

| ゲーム | 人数 | 概要 |
|---|---|---|
| 🎲 ワードスナイパー | 2〜 | お題に合う言葉を、指定された文字から始めて答える |
| 🔢 I T O | 2〜10 | 1〜100の数字をお題の大きさに例えて、小さい順に並べる |
| 🗣️ ボブジテン | 2〜 | カタカナ語をカタカナを使わずに説明する |
| 🍫 キャット＆チョコレート | 2〜 | ピンチな状況を手札のアイテムで切り抜ける |
| 👑 スタック三目並べ | 2 | 駒を重ねられる三目並べ |
| 🐺 ワードウルフ | 3〜10 | 1人だけ違うお題を持つ少数派を探す |
| 🎯 いいセン行きまSHOW！ | 2〜 | 答えが数字の問題で、みんなの答えの中央値を狙う |
| 🧮 10パズル | 1〜 | 4つの数字と四則演算で10を作る |
| 🚫 NGワードゲーム | 2〜4 | 自分だけ見えないNGワードを言ったら脱落 |

## 使い方

`index.html` をブラウザで開くだけです。

ただし Service Worker（オフライン対応）は `file://` では動かないため、
ローカルで動作確認するときは簡易サーバー経由をおすすめします。

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages など静的ホスティングにそのまま置けます（`.nojekyll` 同梱）。

### ホーム画面に追加する（PWA）

スマホのブラウザで開き、「ホーム画面に追加」を選ぶとアプリのように起動できます。
一度開いておけば、電波のない場所でもオフラインで遊べます。

## 機能

- **ひらがなモード** — トップ画面のチェックで、画面の漢字をひらがなに変換します。小学低学年でも遊べます。切り替えてもゲームの進行状況は消えません。
- **スコアボード** — 各ゲームで加点／減点でき、スコアはブラウザに保存されます。プレイヤー名をタップすると改名できます。
- **ダークモード** — 端末の設定に自動で追従します。
- **ルール説明** — ゲーム選択画面の「？」ボタンから読めます。

## お題を追加・編集する

トップ画面右下の ⚙️ から設定画面を開きます。

- ゲームごとのタブでお題を追加・編集・削除できます
- CSV のインポート／エクスポートに対応しています（表示中のリストのみ）
- 変更内容はブラウザの `localStorage` に保存されます

ワードウルフだけは1件が2語のペアなので、`うどん, そば` のように
カンマ・スペース・スラッシュのいずれかで区切って入力してください。

初期のお題そのものを増やしたい場合は `themes.js` を直接編集します。

## ファイル構成

```
index.html            画面（全ページを1ファイルに内包）
style.css             スタイル（CSS変数でライト／ダーク両対応）
script.js             ゲームロジック・設定・ひらがなモード
themes.js             お題データベース（initialThemes）
sw.js                 Service Worker（オフラインキャッシュ）
manifest.webmanifest  PWA マニフェスト
icon.svg              アプリアイコン
```

## 保存データ

すべてブラウザの `localStorage` に入ります。消したい場合はサイトデータを削除してください。

| キー | 内容 |
|---|---|
| `bodoge-themes-v4.5` | 編集したお題 |
| `bodoge-scores-v5` | 各ゲームのプレイヤー名とスコア |
| `hiragana-mode` | ひらがなモードのON/OFF |

## 開発メモ

ビルドもテストランナーもありません。編集したら構文チェックだけ通しておくと安全です。

```bash
node --check script.js
node --check sw.js
```
